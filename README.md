# Sistema De Matrículas

Aplicação de matrículas acadêmicas.

- Front-end: React e Bootstrap
- Back-end: Express
- Dados: arquivo JSON (`data/db.json`), sem MySQL

O servidor entrega o aplicativo já construído e a API. Ele não monta o HTML.

O sistema no ar: https://sistema-de-matriculas-andrews.vercel.app/

## Como abrir no computador

1. Instale o Node.js.
2. Na pasta do projeto, rode `npm install` e depois `npm start`.
3. Abra http://localhost:3000

A senha das contas de demonstração é `123456`. O passo a passo completo está em `LEIA-ME.md`.
